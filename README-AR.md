# وكيل التصفح (Render)

بوت Telegram يستقبل مهمة نصية، فيخطط لها، وإن كانت تتكون من أجزاء مستقلة قسّمها ونفّذها بالتوازي
(كل جزء في متصفح سحابي خاص به عبر Kernel)، ثم يجمع النتيجة. لكل جزء وكيل فرعي بحلقة مراقبة→تنفيذ،
ولا يُقبل جوابه إلا مع اقتباس حرفي من صفحة شاهدها فعلاً.

## النشر على Render
1. أنشئ مستودع GitHub وارفع محتوى هذا المجلد (بدون node_modules و .env).
2. Render ← New ← **Blueprint** ← اختر المستودع (يقرأ `render.yaml`).
3. أدخل الأسرار حين يطلبها Render: `TELEGRAM_BOT_TOKEN` و`NVIDIA_API_KEY` و`ADMIN_TELEGRAM_ID` و`KERNEL_API_KEY`.
4. بعد اكتمال النشر افتح `https://<اسم-الخدمة>.onrender.com/health` (يجب أن يظهر `{"ok":true}`) ثم أرسل `/start` للبوت.

الـ webhook يُسجَّل تلقائياً عند كل تشغيل (Render يوفّر `RENDER_EXTERNAL_URL`)، وسرّه مشتق من التوكن.

## تغيير توكن البوت
Render ← الخدمة ← Environment ← عدّل `TELEGRAM_BOT_TOKEN` ← Save (يعيد النشر تلقائياً ويسجّل الـ webhook من جديد).
ثم ألغِ التوكن القديم من @BotFather بالأمر `/revoke`.

## المتغيرات
| المتغير | الوصف |
|---|---|
| TELEGRAM_BOT_TOKEN | توكن البوت (مطلوب) |
| NVIDIA_API_KEY | مفتاح NVIDIA NIM (مطلوب) |
| ADMIN_TELEGRAM_ID | رقمك في Telegram، هو المصرَّح له الوحيد (مطلوب). ويمكن إضافة آخرين في `ALLOWED_USER_IDS` مفصولين بفواصل |
| KERNEL_API_KEY | المتصفح السحابي (مطلوب، أو STEEL_API_KEY بديلاً) |
| MAX_PARALLEL | أقصى عدد وكلاء متوازين (3) |
| MAX_SESSIONS | حدّ جلسات المتصفح المفتوحة معاً (4) |
| NIM_RPM | حدّ طلبات النموذج في الدقيقة، مشترك بين كل الوكلاء (38) |
| JOB_TIMEOUT_MIN | أقصى زمن لمهمة واحدة بالدقائق (الافتراضي 20؛ مضبوط 12 في render.yaml للخطة المجانية) |
| MODEL_LEADER / MODEL_FALLBACK / MODEL_VISION | لتغيير النماذج الافتراضية |

## الأوامر
`/start` `/help` مساعدة · `/stop` إيقاف المهمة الجارية. مهمة واحدة لكل محادثة، ويتذكر آخر 3 نتائج للمتابعة.

## ملاحظات
- الخطة المجانية في Render تنام بعد 15 دقيقة بلا طلبات واردة (الإقلاع بعد النوم ~دقيقة)، لذلك المهام محدودة بـ 12 دقيقة (`JOB_TIMEOUT_MIN`).
- كل مهمة تبدأ بمتصفح نظيف (لا كوكيز محفوظة)، وهذا مقصود للعزل بين الوكلاء المتوازين.
- لا يعمل على صفحات تتطلب تسجيل دخول لا تملك بياناته، ولا يحاول تجاوز الكابتشا إلا بقراءتها بالرؤية البصرية.

## الاختبارات (للتطوير)
`npm install` ثم `CHROME_PATH=/path/to/chromium npm test`، و`npm run typecheck` للأنواع.
